# Disneyland Paris Tickets

Production-ready web application for **Disneyland Paris Tickets** built with Next.js App Router, Tailwind CSS, Tiptap rich text editor, Neon Postgres database integration, and CMS admin dashboard.

## Key Features
- **Brand**: Disneyland Paris Tickets
- **Primary Focus Keyword**: Disneyland Paris Tickets
- **Color Palette**: Midnight Royal Blue (`#102A5C`), Royal Navy (`#172F6B`), Magic Pink (`#E94B83`), Fairytale Lavender (`#DCD8F2`), Champagne Gold (`#D6A84F`), Cloud Cream (`#FCF8F1`), Soft Sky Blue (`#DCEAF7`)
- **Visual Assets**: Gemini-generated photorealistic theme park imagery
- **CMS & Admin**: Full CRUD capabilities for homepage, ticket products, blog posts, FAQs, and SEO controls
- **SEO System**: Dynamic Schema structured data (`Product`, `Article`, `FAQPage`, `BreadcrumbList`), Robots.txt, and Sitemap.xml

## Getting Started

```bash
npm run dev
```
